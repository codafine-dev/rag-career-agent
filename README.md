# RAG Career Agent

A production-oriented personal AI knowledge agent: a RAG + agent application
over a real software engineering ticket history, built to demonstrate
practical AI application engineering (not ML research).

Status: early scaffold — architecture and implementation in progress.

## Privacy

Ticket data indexed by this project may contain private company information.
See the Privacy section below (to be expanded) for how secrets, credentials,
and raw ticket content are handled.

Full architecture, setup, and usage docs are being written as the project
is implemented.
